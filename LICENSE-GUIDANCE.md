The current distribution is GitHub source or a locally packed npm tarball. npm can install or execute those sources without a registry release. Registry publication is not part of this release; it needs a separate owner decision and a fresh package-content review.

Only project source, documentation, and synthetic examples/tests are intended for distribution. Personal tool configuration, credentials, logs, backups and session history are excluded.
